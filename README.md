Railway Reservation Simulator
About the Project
Developed a Railway Reservation Simulator using **C++ and Object-Oriented Programming (OOP)** to simulate essential railway reservation operations. The system allows users to search for trains, book and cancel tickets, check seat availability, and track reservations using PNR numbers.
The project focuses on implementing core C++ concepts, including OOP principles, STL data structures, operator overloading, file handling, and exception handling. It also features automated waiting-list management, input validation, and a web-based interface to visualize the reservation workflow.
Objectives
- Develop a railway reservation system with essential booking functionalities.
- Implement train search, ticket booking, and cancellation operations.
- Manage seat availability and passenger reservations.
- Implement PNR-based ticket tracking.
- Apply Object-Oriented Programming concepts in a real-world application.
- Use STL vectors and queues for efficient data management.
- Implement file handling for data storage.
- Integrate a web-based interface for reservation workflow visualization.
Key Features
- Train Search: Search for available trains.
- Ticket Booking: Book railway tickets through the reservation system.
- Ticket Cancellation: Cancel existing reservations.
- Seat Availability:Check available seats before booking.
- PNR Tracking: Track reservation details using PNR numbers.
- Waiting List Management: Automatically manage waiting-list reservations.
- Input Validation: Validate user inputs to maintain data consistency.
- Exception Handling: Handle runtime errors and unexpected situations.
- Web Interface: Visualize the reservation workflow using HTML, CSS, and JavaScript.
